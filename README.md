## Overview

Arturia Buchla Easel V is a meticulous software recreation of the iconic Buchla Music Easel, bringing the west-coast synthesis paradigm—with its unique function generators and complex oscillators—to modern DAWs.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Buchla Easel V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Complex Oscillator** | Wavefolder, FM, and waveshaping as in the original Buchla circuit |
| **Sequencer** | Buchla-style 5-stage sequencer with arbitrary stage count and direction |
| **Buchla Lowpass Gate** | Vactrol-modeled lowpass gate for organic plucked and struck timbres |
| **Preset Library** | Hundreds of presets by synthesis pioneers and contemporary artists |
